# 🎵 Spotify Tracks Analysis Dashboard

An interactive **Spotify Tracks Analysis Dashboard** built using **Python** and **Streamlit**. This project performs Exploratory Data Analysis (EDA) on Spotify track data and presents insights through interactive visualizations.

---

## 📌 Project Overview

The objective of this project is to analyse Spotify track data to discover patterns in music characteristics, popularity, genres, and artist trends.

The dashboard provides an easy-to-use interface for exploring the dataset without writing any code.

---

## 🚀 Features

- 📊 Dataset Overview
- 🧹 Data Cleaning & Preprocessing
- 📈 Statistical Summary
- 🎶 Track Popularity Analysis
- 🎤 Artist Analysis
- 🎼 Genre Distribution
- 🔥 Correlation Heatmap
- 📉 Histograms & Distribution Plots
- 📦 Interactive Streamlit Dashboard
- 🎨 Custom Background UI

## 💻 Installation

Clone the repository

```bash
git clone https://github.com/yourusername/spotify-tracks-analysis.git
```

Move into the project directory

```bash
cd spotify-tracks-analysis
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the application

```bash
streamlit run app.py
```
